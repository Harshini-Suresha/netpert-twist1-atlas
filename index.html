NetPert Twist1 Real-Data Atlas

Drug-target prioritisation with network response functions (Perrone et al., PLOS Comp. Biol. 2024) — run on the real IID mouse interactome + TRRUST regulatory network, real Twist1 RNA-seq responses, and real dissemination assays. GitHub repo

Network: 17,191 genes / 1,891,745 directed edges (IID PPI + TRRUST v2). Driver: Twist1. Responses: 168/182 DE genes in-network (14 absent from the interactome). Method: dense NetPert (nt=16, r=0.5) on a 1,200-gene Twist1-centered subnetwork; conservation check 1.99e-15. Betweenness run on the full 17k-gene network. Full table: geneRankings_real.tsv
